# Redirects and SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `plugin-redirects` and `plugin-seo`:
- Admins can map an old Weebly URL to new content without a deploy.
- The site serves those redirects.
- Courses, cycles, programmes, publications, articles, events and press get localized SEO fields. The SEO title, description and image fall back to each document's own title, summary and cover.

**Architecture:**
- **Pure helpers:**
  - `src/lib/paths.ts`: where a document lives on the site.
  - `src/lib/seo.ts`: default SEO values per collection.
  - `src/lib/redirects.ts`: candidate legacy paths, and resolving a redirect to a URL.
- **SEO:** the plugin's generate buttons and the course page's `generateMetadata` use the same helpers. So "filled in automatically" holds whether or not an editor presses Generate.
- **Redirects:** a catch-all route catches any path no other route claims and looks it up in `redirects`. Because Next prefers static segments, `/admin`, `/api` and `/study` are never intercepted.

**Tech Stack:** `@payloadcms/plugin-seo` 3.90.2, `@payloadcms/plugin-redirects` 3.90.2, Next 16 App Router, vitest.

**Spec:** `docs/schema.md` (Plugins).

**Branch:** work directly on `main`, one commit per task. Don't push.

## Decisions made in this plan

- **The redirects collection is admin-only for writes.** The plugin's default lets any signed-in account create, edit or delete redirects, which would let any member hijack any old link. Read stays public, because the frontend route reads it anonymously.
- **Redirect types:** `301` (the default, for archive moves) and `302`.
- **Where redirects may point:** courses, cycles, programmes, publications, articles, events, press and people.
- **`pathOf()`:** only courses have a public route today (`/study/<slug>`). For any other collection `pathOf()` returns null. A redirect to such a document then 404s until its page exists, and the SEO preview URL falls back to the site origin. Each later frontend route adds one line to `pathOf()`.
- **Matching old paths:** a request matches a redirect's `from` exactly. The route also tries the path with and without `.html` and a trailing slash, because Weebly links appear in all those forms.
- **SEO defaults per collection:**

| Collection | Title from | Description from | Image from |
|---|---|---|---|
| courses | `title` | `summary`, else `subtitle` | `cover_image` |
| cycles | `title` | (none) | (none) |
| programmes | `title` | `tagline` | `cover` |
| publications | `title` | `subtitle` | `cover_image` |
| articles | `title` | the opening of `body` | `cover_image` |
| events | `title` | the opening of `description` | (none) |
| press | `title` | `excerpt` | (none) |

- **Title and description format:** titles read "<title> · CILAS". Descriptions are cut to 160 characters at a word boundary, ending with "…".
- **Layout:** no `tabbedUI`. The SEO group sits at the end of each form instead, so the existing layouts don't change.

```ts
import { convertLexicalToPlaintext } from '@payloadcms/richtext-lexical/plaintext'
import type { SerializedEditorState } from '@payloadcms/richtext-lexical/lexical'

/** Collections with SEO fields (docs/schema.md, Plugins). */
export const SEO_COLLECTIONS = [
  'courses',
  'cycles',
  'programmes',
  'publications',
  'articles',
  'events',
  'press',
] as const
export type SeoCollection = (typeof SEO_COLLECTIONS)[number]

type Doc = Record<string, unknown>
type Source = { description?: string[]; richText?: string; image?: string }

// Which of a document's own fields stand in for its SEO fields.
const SOURCES: Record<SeoCollection, Source> = {
  courses: { description: ['summary', 'subtitle'], image: 'cover_image' },
  cycles: {},
  programmes: { description: ['tagline'], image: 'cover' },
  publications: { description: ['subtitle'], image: 'cover_image' },
  articles: { richText: 'body', image: 'cover_image' },
  events: { richText: 'description' },
  press: { description: ['excerpt'] },
}

const MAX = 160

const clip = (text: string): string => {
  const flat = text.replace(/\s+/g, ' ').trim()
  if (flat.length <= MAX) return flat
  const cut = flat.slice(0, MAX - 1)
  return `${cut.slice(0, cut.lastIndexOf(' ')).trim()}…`
}

const idOf = (value: unknown): number | string | undefined => {
  if (typeof value === 'number' || typeof value === 'string') return value
  if (value && typeof value === 'object' && 'id' in value) return (value as { id: number }).id
  return undefined
}

/**
 * The SEO title, description and image a document gets from its own fields.
 * Used by the admin's Generate buttons and as the fallback when meta is empty.
 */
export const seoDefaults = (
  collection: SeoCollection,
  doc: Doc,
): { title?: string; description?: string; image?: number | string } => {
  const source = SOURCES[collection]
  const result: { title?: string; description?: string; image?: number | string } = {}

  if (typeof doc.title === 'string' && doc.title) result.title = `${doc.title} · CILAS`

  const text =
    source.description?.map((f) => doc[f]).find((v): v is string => typeof v === 'string' && !!v) ??
    (source.richText && doc[source.richText]
      ? convertLexicalToPlaintext({ data: doc[source.richText] as SerializedEditorState })
      : undefined)
  if (text) result.description = clip(text)

  const image = source.image ? idOf(doc[source.image]) : undefined
  if (image !== undefined) result.image = image

  return result
}
```

If the `SerializedEditorState` import path doesn't resolve, use the type that `convertLexicalToPlaintext`'s `data` parameter declares. Check `node_modules/@payloadcms/richtext-lexical`.

```ts
import type { Payload } from 'payload'

import { pathOf } from '@/lib/paths'

/**
 * Weebly links appear with and without `.html` and a trailing slash, so a
 * request tries each form, the one asked for first.
 */
export const legacyCandidates = (requested: string): string[] => {
  let path = requested
  try {
    path = decodeURI(requested)
  } catch {
    // Malformed escapes: match the path as given.
  }
  const bare = path.replace(/\/$/, '').replace(/\.html$/, '') || '/'
  return [...new Set([path, bare, `${bare}/`, `${bare}.html`])]
}

type RedirectDoc = {
  type?: '301' | '302' | null
  to?: {
    type?: 'reference' | 'custom' | null
    url?: string | null
    reference?: { relationTo: string; value: unknown } | null
  } | null
}

/** Where a redirect sends people, or null when its target has no page. */
export const redirectTarget = (
  redirect: RedirectDoc,
): { url: string; permanent: boolean } | null => {
  const permanent = redirect.type !== '302'
  const to = redirect.to
  if (to?.type === 'custom') return to.url ? { url: to.url, permanent } : null

  const ref = to?.reference
  if (!ref || typeof ref.value !== 'object' || ref.value === null) return null
  const url = pathOf(ref.relationTo, ref.value as { slug?: string | null })
  return url ? { url, permanent } : null
}

/** Looks up a legacy path in the redirects collection. */
export const findRedirect = async (
  payload: Payload,
  path: string,
): Promise<{ url: string; permanent: boolean } | null> => {
  const { docs } = await payload.find({
    collection: 'redirects',
    where: { from: { in: legacyCandidates(path) } },
    depth: 1,
    limit: 1,
  })
  return docs[0] ? redirectTarget(docs[0] as RedirectDoc) : null
}
```

```ts
/** Meta fields win; the course's own title, summary and cover fill any gaps. */
export async function generateMetadata({ params }: Params): Promise<Metadata> {
  const { slug } = await params
  const payload = await getPayload({ config })
  const { docs } = await payload.find({
    collection: 'courses',
    where: { slug: { equals: slug } },
    limit: 1,
    depth: 1,
    joins: false,
  })
  const course = docs[0]
  if (!course) return {}

  const fallback = seoDefaults('courses', course as unknown as Record<string, unknown>)
  const meta = course.meta ?? {}
  const image = typeof meta.image === 'object' && meta.image ? meta.image : course.cover_image
  const imageUrl = typeof image === 'object' && image?.url ? image.url : undefined
  const title = meta.title || fallback.title
  const description = meta.description || fallback.description

  return {
    title,
    description,
    openGraph: { title, description, ...(imageUrl ? { images: [imageUrl] } : {}) },
  }
}
```

```tsx
import config from '@payload-config'
import { notFound, permanentRedirect, redirect } from 'next/navigation'
import { getPayload } from 'payload'

import { findRedirect } from '@/lib/redirects'

type Params = { params: Promise<{ path: string[] }> }

/**
 * Old Weebly URLs. Next tries every static route first, so this only sees
 * paths nothing else claims; each is looked up in `redirects`, which admins
 * edit without a deploy.
 */
export default async function LegacyPath({ params }: Params) {
  const { path } = await params
  const payload = await getPayload({ config })
  const target = await findRedirect(payload, `/${path.join('/')}`)
  if (!target) notFound()
  if (target.permanent) permanentRedirect(target.url)
  redirect(target.url)
}
```
